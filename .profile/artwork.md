# Profile header

The active header is authored directly in SVG, with typography and an original glasses and psychic limiter emblem inspired by Saiki Kusuo. It contains no generated bitmap or external image dependencies.

- Dark: `assets/profile-v5/header-saiki-emblem-dark.svg`
- Light: `assets/profile-v5/header-saiki-emblem-light.svg`
- Source: `scripts/build_profile.py`

Rebuild with `python scripts/build_profile.py`; validate with `python scripts/validate_profile.py`.

The previous generated image remains archived as `assets/saiki-scene.png` and is no longer used in the README.
